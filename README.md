# 🚀 Modern Portfolio Website - Ach. Faisol S. Arifin

Sebuah website portfolio modern yang direvamp dengan desain estetik, responsif, dan berbagai efek visual yang menarik.

## ✨ Fitur Utama

### 🎨 Desain Modern
- **Glassmorphism Design**: Efek kaca transparan dengan blur backdrop
- **Dark Theme Support**: Tema gelap dengan toggle yang smooth
- **Gradient Backgrounds**: Warna gradient modern yang menarik
- **Typography Modern**: Font Inter dan JetBrains Mono yang profesional

### 🌟 Efek Visual
- **Particle Background**: Partikel animasi yang mengambang di background
- **Smooth Animations**: Animasi AOS (Animate On Scroll) yang halus
- **Hover Effects**: Efek hover yang responsif dan menarik
- **Magnetic Buttons**: Tombol yang mengikuti pergerakan mouse
- **Parallax Scrolling**: Efek parallax pada background hero

### 📱 Responsif & Interaktif
- **Fully Responsive**: Desain yang sempurna di semua ukuran layar
- **Touch Friendly**: Optimized untuk perangkat mobile
- **Keyboard Navigation**: Dukungan navigasi keyboard untuk accessibility
- **Custom Cursor**: Cursor kustom dengan efek interaktif (desktop only)

### 🎯 Navigasi Modern
- **Tab Navigation**: Sistem tab modern dengan indikator aktif
- **Smooth Scrolling**: Scroll yang halus antar section
- **Progress Indicator**: Bar progress saat scrolling
- **Dynamic Content Loading**: Konten dimuat secara dinamis

### 📊 Section Konten
- **About Section**: Profil lengkap dengan statistik animasi
- **Education Timeline**: Timeline pendidikan dengan marker modern
- **Experience Timeline**: Pengalaman kerja dengan skill tags
- **Portfolio Grid**: Grid portfolio dengan overlay efek
- **Research Publications**: Publikasi penelitian dengan metadata
- **Articles Section**: Section artikel (coming soon)

## 🔧 Customization

### Mengubah Tema Warna
Edit variabel CSS di `css/style.css`:
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
  /* ... */
}
```

### Menambah Animasi
Tambahkan di `css/effects.css`:
```css
.your-animation {
  animation: yourKeyframes 1s ease-in-out;
}
```

### Menambah Section Baru
Implementasi di `js/script.js`:
```javascript
function createYourSection() {
  return `<!-- Your HTML here -->`;
}
```
